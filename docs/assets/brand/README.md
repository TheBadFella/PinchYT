# Pinchflat-ngx Brand Assets

This directory contains official logos, icons, and visual assets for **Pinchflat-ngx**.

## Files

| File                         | Format                | Dimensions       | Usage                                                    |
| :--------------------------- | :-------------------- | :--------------- | :------------------------------------------------------- |
| [`logo.png`](logo.png)       | PNG (Transparent)     | 1102 &times; 270 | Primary wordmark + monogram logo lockup (HiDPI / Retina) |
| [`logo.svg`](logo.svg)       | Scalable Vector (SVG) | Scalable         | Primary vector logo lockup                               |
| [`icon.png`](icon.png)       | PNG (Transparent)     | 250 &times; 250  | Monogram app icon mark                                   |
| [`icon.svg`](icon.svg)       | Scalable Vector (SVG) | Scalable         | Vector app icon mark                                     |
| [`favicon.ico`](favicon.ico) | ICO                   | Multi-res        | Browser favicon                                          |

## Design Tokens

- **Monogram Mark**: Isometric dimensional ribbon folding the initial letter **P** into an integrated playback chevron.
- **Background Surface**: Material 3 AMOLED Dark (`#0d0b10` / `#000000`)
- **Primary Accent**: Lilac (`#d0bcff`)
- **Secondary Accent**: Electric Rose (`#efb8c8`)
- **Container Surfaces**: Deep Violet (`#4f378b` / `#332d41`)
- **Typography**: Google Sans Code / Geometric Sans-serif with `-ngx` accent
